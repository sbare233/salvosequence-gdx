# 音效素材（占位）

这些 WAV 不是录来的，是脚本按参数合成出来的**占位音**——先把链路跑通，
真音效到位后覆盖同名文件即可，代码一行都不用改。

## 规格

| 项目 | 值 |
| --- | --- |
| 容器 | RIFF/WAVE，PCM |
| 采样率 | 44100 Hz |
| 声道 | 单声道 |
| 位深 | 16 bit 有符号小端 |
| 长度 | 0.07 ~ 1.70 秒（UI 音短、爆音长） |

## 清单

| 文件 | 音色 | 时长 | 用途 |
| --- | --- | --- | --- |
| `click.wav` | 短方波 | 0.07s | 菜单确认 |
| `beep.wav` | 正弦 | 0.09s | 菜单移动 |
| `shot_light.wav` | 高频方波 + 快速衰减 | 0.10s | 轻武器开火 |
| `shot_heavy.wav` | 低频方波 + 噪声 | 0.16s | 重武器开火 |
| `hit.wav` | 噪声爆点 | 0.12s | 命中 |
| `explode.wav` | 噪声 + 低频扫落 | 0.54s | 击毁 |
| `alarm.wav` | 双音告警 | 0.68s | 掉血告警（随伤势变急） |

## 想换真音效

1. 用 Audacity 等工具导出成 PCM WAV（**单声道 44.1k 16bit** 最省事，
   其它规格也能读：加载时会自动转成 44100Hz 单声道）；
2. 覆盖 `src/main/resources/sounds/` 下的同名文件，**文件名必须一致**
   （`SoundId` 里的常量按文件名找）；
3. `mvn -o -Paudio javafx:run` 自检——它会逐个加载并打印规格、时长、峰值、有效值，
   默认连播一遍让你听（只想静音量数据就设环境变量 `AUDIO_PLAY=false`）。

> 别改文件名。要加新音效就在 `SoundId` 里加一个常量，再放同名 WAV。

## 播放后端

走 JDK 自带的 `javax.sound.sampled`（`java.desktop` 模块），**不是** `javafx.media`：

- 混音器（`audio/Mixer`）常开一条 `SourceDataLine`，把同时响的音效混进同一个缓冲区
  （每个混音块 4096 帧，约 20ms 触发延迟），所以连射不会互相打断，
  也不会因为反复开设备而卡顿；
- 输出格式固定 44100Hz / 16bit / 立体声，音源在加载时统一转换，播放路径里没有格式分支；
- 没有声卡、或设备被独占时，打印一行原因后<b>永久静音继续跑</b>，不会崩；
- 分发包不用再带 `javafx.media`，也不会再出现
  `UnsatisfiedLinkError: no glib-lite in java.library.path`。

听不到声音时按这个顺序查：

1. `mvn -o -Paudio javafx:run` —— 峰值≈0 说明素材本身是静音的；
2. 设环境变量 `AUDIO_DEVICES=true` 再跑一次——会列出声卡，看默认设备是不是通往
   没人听的输出（装了 Steam Streaming Speakers 之类的虚拟声卡时尤其要看）；
3. 峰值正常但没声音，且日志里出现「音频不可用」——那是设备被独占或驱动问题。
